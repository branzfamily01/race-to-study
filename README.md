# Race to Study

勉強時間をレーシングゲームの進行に変換する、モバイル向け学習タイマーPWAです。

## 構成

- `index.html` — アプリ本体（UI / ロジック / CSSを内蔵）
- `assets/supercar.webp` — 生成画像を元にしたリアル調スーパーカー素材
- `manifest.webmanifest` — PWA設定
- `sw.js` — オフラインキャッシュ
- `icon.svg` — ホーム画面用アイコン

## 主な機能

- リアル調スーパーカーを使ったガレージ画面
- 11車種選択（車名とカラー演出の切り替え）
- エンジン始動演出
- 教材登録・個別削除（保護者コード `1234`）
- 5 / 10 / 15 / 20 / 25 / 30 / 45 / 60分の集中タイマー
- 学習ポイント・連続学習・3日ごとのボーナス
- 20種類のパーツ解放
- 全パーツ解放後のレース
- 端末内自動保存（localStorage）
- 引き継ぎコードによるデータ移行
- PWA / ホーム画面追加 / オフラインキャッシュ

## GitHub Pagesで公開

`Settings → Pages` を開き、Sourceを `Deploy from a branch`、Branchを `main` / `/ (root)` に設定してください。

## データ保存

学習データはブラウザのlocalStorageに保存されます。ブラウザデータを削除すると消えるため、必要に応じて「引き継ぎ」画面からコードを保存してください。
